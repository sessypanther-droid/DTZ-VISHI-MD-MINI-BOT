# DTZ VISHI MD
DTZ VISHI MD is a multi-device WhatsApp bot designed to provide enhanced functionality and automation for WhatsApp users.

## Deployment

- **Platform:** Railway
- **Database:** MongoDB
- **Start command:** `npm start`

Set these Railway Variables before deploying:

- `MONGODB_URI` — your MongoDB connection string
- `OWNER_NUMBER` — comma-separated WhatsApp owner numbers without `+`
- `OWNER_NAME` — defaults to `VISHI`
- `BOT_NAME` — defaults to `DTZ VISHI MD`
- `SESSION_ID` — optional session identifier
- `CHANNEL_LINK` — defaults to the DORA-MD MINI BOT WhatsApp channel
- `CHANNEL_AUTO_FOLLOW` — defaults to `true`; set to `false` to disable automatic channel following
